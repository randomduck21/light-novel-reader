# Built-in test chapter

The packaged extension includes `test/test.html` so the reader can be tested without relying on a particular novel website.

1. Open the test page from the installed extension package.
2. Click the extension toolbar button.
3. Choose **Read current page**.
4. In the reader tab, press **Play**.
5. The first run downloads the selected Piper voice model.
6. Once synthesis begins, upcoming chunks are buffered ahead of playback.
